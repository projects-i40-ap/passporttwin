# Sesiones de PassportTwin con Codex

Usar `TEMPLATE.md` para cierres que permitan continuar entre Pau y Alexander.
Guardar cada registro como `AAAA-MM-DD-persona-tarea.md`; añadir un sufijo si hay varias sesiones del mismo tema en un día.

Prompt de inicio:

> Soy [persona]. Lee AGENTS.md y el último cierre relacionado. Revisa la tarjeta [tarea] o su exportación, el estado local y remoto y posibles solapamientos. Trabaja en [objetivo] siguiendo sus criterios. Comprueba el código antes de asumir el estado descrito en los chats.

Prompt de cierre:

> Cierra la sesión con la plantilla: cambios, evidencia, comprobaciones y resultados, estado de Git, pendientes y siguiente paso. Prepara el texto para Notion e indica si se ha publicado. Distingue lo implementado de lo validado.

Estos registros complementan Notion y GitHub. Las decisiones duraderas deben pasar a la documentación técnica correspondiente.
